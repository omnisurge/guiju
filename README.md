# 规矩 guiju

> 以规范为准绳，让依据随手可取。
> 命令行 `guiju`（别名 `gj`）· 面向监理与工程技术人员 · 主路径是 `--json`

从 `*.gov.cn` 采集**工程建设标准公告目录与正文**，并生成可直接粘贴进监理文书的**标准引用串**。

**定位**：它是「监理内业助手」的取源环节 —— agent 干活时需要可靠信源，它负责把一个编号
变成**可核验的正文**（sha256 对得上官方发布件）和**可引用的字符串**；取不到时说清原因，
**绝不拿相近的另一本顶上**。

查规范 → 取正文 → 出引用串，三件事做完就停。

---

## 先说清楚边界（请务必读完这三条）

1. **本工具不生产内容，只做搬运与校验。** 不承诺条文准确性；条文解释以正式出版物为准。本工具只保证：本地文件与官方发布件**内容一致**（sha256 可复核）。
2. **只抓政府已主动公开的内容。** 依据《标准化法》第 17 条：强制性标准文本应当免费向社会公开，国家推动推荐性标准免费公开。
3. **不做分发。** 本项目不提供标准文件的下载站、镜像或转售 —— 那才是侵权。工具在你自己机器上为你自己取证。

## 安装

纯标准库，Python **3.10+**，无需 `pip install` 任何运行时依赖。

```bash
# 方式一：直接跑（不安装）
python3 -m guiju --help

# 方式二：装成命令（推荐）
uv tool install --editable .     # 或 pipx install .
guiju --version
gj --version                     # 等价别名
```

数据默认放 `~/.guiju/`（目录库 `catalog.db` + 正文 `library/`）。用 `GUIJU_HOME` 或 `--db` 覆盖。

> 若在受限沙箱里运行，`~/.guiju` 可能被安全策略拦（报 `disk I/O error`），
> 此时 `export GUIJU_HOME=/tmp/guiju` 即可 —— 不要误判为代码缺陷。

## 五分钟上手

```bash
# 1) 同步目录（首次全量约 1 分钟；之后增量，通常 1 页内完成）
guiju sync

# 2) 检索（纯本地，不联网、秒回；书名号可带可不带）
guiju search 防火 --json
guiju search 《防火》 --all          # 43 条：所有名称含「防火」的标准

# 3) 查一个编号到底是什么（权威状态 + 本地公告 + 有无正文）
guiju which GB55037-2022
# → GB 55037-2022　现行　建筑防火通用规范　实施 2023-06-01
#    本地公告：#158 建筑防火通用规范（2023-01-19）

# 4) 下载正文（幂等：已存在且校验通过则返回退出码 10）
guiju pull GB55037-2022 --json

# 4b) 批量：给一个清单文件（清单本身就是范围，不需要再切）
guiju pull --source shzjw DG/TJ08-2007 --json   # 上海地标（地方标准正文）
guiju pull --list refs.txt --json
cat refs.txt | guiju pull --list - --json          # 或走 stdin

# 5) 出引用串
guiju cite GB55037-2022 5.2.1
# → 《建筑防火通用规范》GB 55037-2022 第5.2.1条

# 6) 看一眼自己手里有什么
guiju status
```

## 命令

| 命令 | 作用 | 联网 |
|---|---|---|
| `guiju sync` | 增量同步公告目录（遇 0 新增即停）；`--if-stale 7` 给定时任务，新则 0 请求秒退 | 是 |
| `guiju search <关键词…>` | 本地检索公告（子串 + 模糊三层召回） | 否 |
| `guiju which <编号\|名称>` | 权威时效 + 本地公告 + 有无正文（**推荐入口**） | 是* |
| `guiju index` | **已废弃（ADR 0001）**：不再是任何命令的前置条件，待移除 | 是 |
| `guiju show <ref>` | 名称/编号/角色/可得性/本地文件 | 否 |
| `guiju pull <ref>` | 下载正文（流式落盘 + 断点续传），幂等，内容寻址归档 | 是 |
| `guiju pull --list f.txt` | 按清单批量下载，汇总成功/已存在/未达成 | 是 |
| `guiju cite <ref> [条款]` | 生成引用串（`--strict` 有未核实项即失败） | 否 |
| `guiju verify` | 校验归档完整性（缺失/被改） | 否 |
| `guiju provenance <路径>` | 按 sha256 反查来源 | 否 |
| `guiju status` | 库状态、覆盖度、可得性口径 | 否 |
| `guiju version` | 版本与目录台账 | 否 |

`<ref>` 支持四种写法：**规范名**（`建筑防火通用规范`）、标准编号（`GB55037-2022` / `GB 55037` / `55037`）、公告 ID、公告 URL。

- 规范名走本地检索（`domain/search.py` 三层召回），多候选即退出 32 让你选。
- **编号不需要预先建索引**：本地查不到就问 `spec-currency` 拿权威名称与现行状态，再按名称定位公告。
- `cite` 会做权威状态校验：被替代/废止的版本进 `warnings`，`--strict` 直接失败。
- `*` 仅 `which`/`cite` 访问时效服务；`--offline` 可完全离线。

全局开关：`--json`（stdout 只有 JSON）、`--quiet`、`--db PATH`。

### 检索行为（三层召回，结果按相关性排序）

| 层 | 触发 | 例子 |
|---|---|---|
| `and` | 子串命中（多关键词为「与」） | `防火` → 43 条；`防火 设计` → 同时含两者 |
| `fuzzy` | 中文插字导致二元组断开 | `防火规范` → 补回《建筑防火通用规范》 |
| `chars` | 召回不足 3 条时放宽到字符全覆盖 | `给排水` → 《建筑给水排水设计规范》 |

`--json` 会返回 `mode`（`and`/`fuzzy`/`chars` 及其组合）与 `total`/`count`/`truncated`，
每条结果带 `match`（`exact_name`/`prefix_name`/`contains_name`/`contains_code`/`fuzzy`）与 `score`。

注意：**未 `index` 的条目没有编号**（`codes: []`）。名称检索不需要 index，按编号检索才需要。

## 重要事实：正文可得性按年份分档

这是使用前必须知道的一件事，**不是缺陷，是现实**：

| 公告发布年份 | 正文可得性 | 说明 |
|---|---|---|
| **2014 年及以后** | 基本都能取到 | 抽样每年 2/2 命中；拿不到属异常，值得排查 |
| **2014 年之前** | 多为「只有名称与编号」 | 抽样仅零星有附件；工具会明确告知「这不是故障，不需要重试」 |

实测口径（2026-10-30，54 条分层样本）：全库约 **52%** 的公告带正文附件。

工具不会让你猜：每条失败都带 `availability`（`in_window` / `pre_window`）与一句中文 `hint`。
`guiju status` 也会把这条口径打印出来。

## 退出码（稳定契约）

| 码 | 含义 | agent 该怎么做 |
|---|---|---|
| 0 | 成功（含「搜索无结果」） | 继续 |
| 10 | 已存在且校验通过 | 跳过，别重复下载 |
| 20 | 源不可达 | 稍后重试 |
| 30 | 公告页没有正文附件 | 看 `hint`：pre_window 属正常事实，别重试 |
| 31 | 编号未索引 | 先 `guiju index` |
| 32 | 编号有歧义（新旧版本/多候选） | **让人选**，禁止按年份自行猜 |
| 33 | 多个附件且无法判定 | **让人选**，禁止兜底取第一个 |
| 40 | 命中合规护栏 | **停止**，不重试、不换路径 |
| 50 | 站点结构变更/需人工 | 上报维护者修适配器 |
| 2 | 输入无法解析（参数/条款号） | 按 hint 修正输入，别重试同样输入 |
| 1 | 程序缺陷（会同时打印 traceback 到 stderr） | 带 traceback 上报 |

`--json` 下失败体统一为：
```json
{"ok": false, "exit": 33, "reason": "ambiguous_attachment", "error": "…", "hint": "…", "candidates": [...]}
```

## 合规红线（不提供 override 开关）

- 仅允许 `*.gov.cn`，且**每一次重定向**都重新校验（见 `guiju/compliance.py`）
- 限速 1.2 秒/请求（按 host），宁可慢，不可打
- 诚实 UA，不伪装浏览器
- 命中验证码/人机校验**立即放弃**，不尝试绕过

## 明确不做

1. 不做标准文件的公开分发/镜像/网盘
2. 不抓团体标准（T/CECS）、不抓标准图集（G101）—— 无官方公开渠道
3. 不绕过任何验证码、登录、付费墙
4. 不解析条文内容、不做智能问答 —— 只生成引用串
5. 不提供高频并发抓取；限速是产品的一部分，不是可调参数
