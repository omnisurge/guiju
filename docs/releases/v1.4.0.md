# guiju v1.4.0

- wheel：`guiju-1.4.0-py3-none-any.whl`
- sdist：`guiju-1.4.0.tar.gz`
- 验证：完整联网 e2e **39/39** + 国标电子书库图集真链点查；Python 3.10/3.13 各 **1279 项单测**；POSIX-only（Linux / macOS），运行时零第三方依赖；PEP 639 零弃用警告打包。
- 主要变更：
  - **标准图集有效期与替代链校验（ADR 0007）**：接入官方国标电子书库（`ebook.chinabuilding.com.cn`）原生时效适配器 `chinabuilding`（方案 A：列表检索 + 废止条目追加 1 次 `detail/show` 提取 `replaced_by`），覆盖国标/中南标/28 省前缀地方图集/合订本/`DBJ/T02-...-12D1` 等 4,252 条编码模式，严格隔离 `B` 双语/`英文版`/同族兄弟号/上海地标；`DiskCurrencyCache` 向下兼容 `v1.3.0` 存量缓存。
  - **完整图集目录索引与 CLI/MCP 扩展**：新增独立只读快照 `GUIJU_HOME/atlas-catalog.json`（不触碰 `catalog.db` `SCHEMA_VERSION = 2`）、CLI 命令 `guiju atlas {sync|search|list}` 与 MCP 只读工具 `atlas_search`；`which` 支持汉字省前缀图集号并展示 `replaced_by`，`pull`/`cite`/MCP `announcement` 显式拒绝下载图集正文（`copyright_atlas`，零下载请求）。
  - **显式年份防跨版替代与工程治理**：修复 `resolve._pick_record` / `_by_code` 对显式带 4 位版年的编号（如 `JGJ 147-2004`）误以同族新版（如 `JGJ147-2016`）顶替的问题；`pyproject.toml` 升级至 PEP 639（消除 `SetuptoolsDeprecationWarning`）；拆分 `AGENTS.md`（开发约束）与 `docs/AGENT-USAGE.md`（消费方契约），并沉淀 `.agents/skills/red-team-review/SKILL.md`。
