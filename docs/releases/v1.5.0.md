- 主要变更：
  - **开发态与使用态 Agent 约束/技能解耦与单一真源（ADR 0008）**：包内新增 `guiju/agent_assets/`（`contract.md` 唯一正文真源、`skill_frontmatter.yaml` 纯头信息、`history_hashes.json` 跨版本哈希映射），运行时确定性拼接完整 `SKILL.md` 并由 MCP `initialize` 运行时按标记区间提取 `instructions`；`docs/AGENT-USAGE.md` 收敛为极简指针页，双层净化守卫（wheel 黑/白名单 + 消费方 5 处可见输出词法/死链扫描）保证零仓内开发文档/源码路径/技能泄露。
  - **跨 Harness 显式分发器 `guiju agent` 与带外收据状态机**：新增 `guiju agent {show|install|uninstall|status}`（完全绕开 `catalog.db` 与 `autosync`），严格保持 `domain/agent_assets.py` 纯逻辑、`store/agent_receipts.py` 带外持久化（`GUIJU_HOME/agent-receipts.json`，`schema: 1` + POSIX `fcntl.flock` + `.corrupt-<ts>` 备份）与 `application/agent.py` 编排；支持团队 `git pull` / `git checkout` 同步、跨机历史哈希认领（`adopted`/`adopted_and_upgraded`）、缺失目录清陈旧收据、`--force`、以及包含祖先符号链接（含 Python 3.10/3.13 symlink loop）在内的全面 `lstat`/`O_NOFOLLOW` 拒绝，绝不触碰同级其他工具技能。
  - **退出码契约与发版防回流门禁**：在 `guiju/errors.py` `1x` 本地文件系统段新增 `EXIT_CONFLICT = 11`（`AgentConflict`，MCP 服务面永不返回 `11`），保持 `SCHEMA_VERSION = 2` 及既有规范业务退出码零变更；`README.md` 退出码表补齐 `34` 与 `11` 并由单测校验与 `EXIT_TABLE | {EXIT_INTERNAL}` 及 `contract.md` 三方一致；`scripts/check-release.py --artifacts` 新增 wheel 内容黑白名单与基于已发布 tag 的 `history_hashes.json` 只增不改校验。
