# guiju v1.3.0

- wheel：`guiju-1.3.0-py3-none-any.whl`
- sdist：`guiju-1.3.0.tar.gz`
- 验证：完整联网 e2e **39/39**；Python 3.10/3.13 各 **1224 项单测**；POSIX-only（Linux / macOS），运行时零第三方依赖。
- 主要变更：
  - **M4 改版观测闭环**：新增 `guiju sources [--probe] [--json]`，`announcement.body_sha256` 落库与内容变化识别（`pull` JSON 附带 `body_sha256`/`body_changed`），`MetadataClient` 接入 `probe_sink`。
  - **架构与测试收敛**：清理 `CachedCurrency` 不可达缓存与 `Store.search()`，缩窄 `McpServer._announcement` 锁；删除 `guiju/compliance.py`、`guiju/currency/httpx.py`、`guiju/cli/{lookup,render}.py` 与 `application/` 隐式构造兜底并由 `AppContext` 统一装配；33 个按批次命名的回归测试零删减归并进领域套件并设命名守卫。
  - **破坏性变更与升级说明**：MCP `batch` 移除服务端文件路径 `list`/`out`（仅接受内联 `codes[]`）与 `backend.lookup()` 单线程兼容路径，`_ReadOnlyStore` 收敛为白名单只读代理；`search`/`show` 人读主结果改为 `stdout`；数据库 `SCHEMA_VERSION` 维持 `2`，与 `1.2.0` 双向升级/回退零迁移。
