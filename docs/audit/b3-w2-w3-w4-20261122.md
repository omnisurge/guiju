## 4. 行为细节

### W2
- `mohurd.catalog_page`：空 fragment → `([], None)`；有 fragment 无计数 → `(items, None)`；明确计数 0 → `(items, 0)`。
- `syncengine`：不再写 `catalog_complete`；成功写 `sync:<source>:complete/synced_at`，不完整不写 synced_at；旧 `catalog_complete` 仍可读。
- `autosync`：`auto_sync_failed_at:<source>` 冷却，mohurd 兼容旧全局键；`catalog.sources` 保持当前源数组语义；新增 `sources_all`（registry 顺序、未同步 stale）与 `aggregate`（complete=所有源、age=max 且任一 None 则 None、state 最坏、reason 为 source=reason 或 source=unknown）。
- `status`：`schema_version=SCHEMA_VERSION`；阈值 `MAX_AGE_DAYS`；顶层和每源 `catalog_meta_corrupt`；未来超过 1 小时的 synced_at 返回 None/corrupt。
- W2 测试文件：`tests/test_b3_baseline_20261122.py`、`tests/test_b3_w2_sync_status.py`。

### W3
- 保持 `guiju/currency/*` 生产代码不变。
- `cli/lookup._by_code`：`completeness_of(currency)`；当无匹配 target 且 `complete is False` 时抛 `NeedsHuman(50)`，附 `currency_complete=False` / `currency_incomplete_reason`；`complete True/None` 仍走 `NotIndexed(31)`。
- W3 测试文件：`tests/test_b3_w3_lookup.py`；既有契约：`tests/test_currency_w3_contract.py`（51 tests）。

### W4
- `upsert_announcement`：`INSERT OR IGNORE` + 条件 UPDATE；保留 id、首次 `fetched_at`。
- `find_by_code` / `search`：LIKE 元字符（百分号、下划线、反斜杠）统一转义并加 `ESCAPE`。
- unknown schema → `NeedsHuman(50)` + hint；CLI 捕 `sqlite3.DatabaseError`：locked/busy→20，其余→50。
- W4 测试文件：`tests/test_b3_w4_store.py`。
