## 已覆盖的残余缺陷

- P2-14：body/metadata 4xx 错误体读前 64KB 做 BlockDetector；403/429+marker → 40 且不重试。
- P2-15：`.part.meta` 强 ETag/Last-Modified sidecar；Range + If-Range；weak/无验证器/响应验证器缺失全量重下；416 仅强验证器+长度匹配才接受；HEAD 唯一 `transport.probe`。

- W1 P3：GET 8MiB 上限、download 512MiB 上限、metadata 2MB；BlockDetector 前 64KB（utf8/gbk/实体/转义/xhtml/英文 marker）；`mohurd.download` 走 `download_bytes` 不走 `get_page`；所有 opener `ProxyHandler({})`。
- B2/B5/B8：`pull.py` 只经 `net.body.finalize` 落位；`BodyClient` 无 `post_json`；`currency/httpx` 与 `compliance` 为 facade，无 `_opener`；`Throttle` 每 host 锁，不同 host 互不阻塞；IDN canonical_host + URL 控制字符/端口/凭据校验。
